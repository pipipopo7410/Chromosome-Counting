# 生殖網站｜原版保留 12 項精修版

**原始底稿：** 使用 `chromosome-main.zip`（GitHub 專案 chromosome）內的 `index.html`，保留原有染色體圖形、顏色、點擊計數、`+1 條`、配對物件停留細胞內及原本的交配與受精動畫。這不是先前重新設計介面的 2.0 版。

## 上傳 GitHub Pages

1. 將本 ZIP 解壓縮，**選取解壓後資料夾內的所有檔案**，直接上傳到新 GitHub 儲存庫根目錄（確保 `index.html` 在根目錄）。
2. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/(root)` → Save。
3. 用新網址打開測試，建議以 iPad 橫向操作。

## 明確修改範圍（12 項）

01. 數完染色體後、進入數對前加入指定預測題。
02. 數套前預測、操作完成後核對。
03. 精子與卵子先填 5 項預測，再操作，完成後核對。
04. 用中央放大表格代替原本精卵階段的小型即時答題選單。
05. 第一次遊玩固定果蠅 → 跳鼠 → 牡蠣，不能跳過跳鼠。
06. 三關完成後，解鎖三關自由重練；重新開啟頁面則重新按順序進行。
07. 補入已確認的跳鼠交配插畫 `11.webp`。
08. 牡蠣交配環節出現「牡蠣是體外受精，你在期待什麼...= =？」對話。
09. 三倍體文字改成「減數分裂可能較難正常分配、生殖能力通常下降，但不是一律無法生殖」。
10. 16 張圖片轉成無損 WebP（轉換前後 RGBA 像素一致），搭配首頁優先載入與分階段預載。
11. 保持原版染色體色彩、計數漂浮、原磁吸距離；配對優先選最近候選，配子形成階段微幅減速。
12. 拆解與分套時清理已失效的舊拖曳實例；新 UI 獨立放在 `learning-additions.js`、`learning-additions.css`。

## 驗收重點

- 開頭數 10 條時，點擊後停止漂浮、出現 `+1 條`；數完直接跳預測問題。
- 同源染色體配對後留在細胞內，可繼續拖曳，不會自動飄走。
- 配對完成 → 核對 → 預測幾套 → 原版組套操作。
- 精子、卵子各先填預測，再拆解拖曳，完成後能核對答案。
- 第一關只可選跳鼠；第二關只可選牡蠣；第三關完成後可自由重練。
- 跳鼠交配圖片顯示，牡蠣顯示指定台詞。
- iPad Safari 橫向和直向、點按、雙擊拆解與拖曳手感。

## 技術說明

- `index.html` 包含原版所有核心動畫、資料與互動。補充功能在新增的 JS/CSS 檔中，**請勿只上傳 `index.html`**。
- 原版 GSAP 及 Draggable 仍透過原本的 cdnjs 網址載入，因此網站需要可連到該 CDN 才能正常操作；圖片本身都從 GitHub 網站載入。
- 已完成 JavaScript 語法檢查、圖片逐像素比對、原版流程的模擬互動檢查。實際 iPad Safari 手勢和真實 GSAP 動畫仍需要部署後驗收。
