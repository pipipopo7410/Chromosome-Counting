# 生殖網站｜原版保留・追加 6 項微調

本網站可直接部署到 GitHub Pages。**本版以使用者提供的 `chromosome-main.zip` 為原始底稿，承接上一版的 12 項改動，再追加 6 項微調。** 沒有使用先前整站重製版。

## 上傳 GitHub

1. 解壓縮這個 ZIP，選取資料夾內所有檔案，一次上傳至新儲存庫根目錄。請確認 `index.html` 在根目錄，而非放在多一層資料夾中。
2. 到 GitHub 儲存庫 Settings → Pages → Deploy from a branch，選擇 `main` 和 `/(root)`。
3. 網站公開後建議以 iPad Safari 橫向完成實測，再決定是否取代舊版。

## 本次 6 項微調

1. **精子預測題**：改為「這隻果蠅有10條染色體，那精子內有多少條染色體？」；移除題目下方多餘說明。跳鼠同樣套用其染色體數量。
2. **配子表格顏色**：新版預測／核對表中，體染色體以藍色、性染色體以粉紅色區分。原版實際染色體的顏色、形狀完全沒改。
3. **簡短答對回饋**：例如「2套，完全正確！」；答錯時簡潔顯示正確值與原預測。精子、卵子的五項比對仍保留。
4. **另一性別挑戰**：系統記錄果蠅受精後寶寶性別；進入跳鼠的精子操作前，邀請試著產生另一種性別的寶寶，也能選擇自由操作。結果依學生真正選入精子的性染色體決定，系統不會替學生指定。**這是 XX/XY 教學模型，不是現實中能自主決定子女性別的操作方法。**
5. **牡蠣高中先修自選**：跳鼠完成後出現「牡蠣是高中課程，想挑戰看看嗎？」選「好」即開始牡蠣；選「還是回去多操作多複習幾次鞏固記憶」可複習已完成的果蠅或跳鼠，之後仍有「準備好了，挑戰牡蠣」入口。三關全通關後才開放三關自由重練。
6. **漂浮碰撞評估**：檢查後保留原版物理運算，不修改已驗收滿意的點選停止、`+1`、磁吸、碰撞與拖曳。若未來需要調整，建議另開獨立體感實驗版本。
