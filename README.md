# 生殖網站｜原版保留・追加 3 項精修（承接前版 12＋6 項）

本網站可直接部署到 GitHub Pages。**本版以使用者提供的 `chromosome-main.zip` 為原始底稿，承接上一版的 12 項改動，再追加 6 項微調。** 沒有使用先前整站重製版。

## 上傳 GitHub

1. 解壓縮這個 ZIP，選取資料夾內所有檔案，一次上傳至新儲存庫根目錄。請確認 `index.html` 在根目錄，而非放在多一層資料夾中。
2. 到 GitHub 儲存庫 Settings → Pages → Deploy from a branch，選擇 `main` 和 `/(root)`。
3. 網站公開後建議以 iPad Safari 橫向完成實測，再決定是否取代舊版。

## 本次新增 3 項（2026-11-13）

1. **牡蠣對話**：拿掉標題「牡蠣說：」，保留「牡蠣是體外受精，你在期待什麼...= =？」和體外受精簡短解釋。
2. **配對／分套前的預測卡片**：從畫面中央移到細胞旁的空白處，不顯示霧化遮罩。直向空間足夠時放在細胞上方；狹小螢幕僅在作答期間暫時縮小細胞，送出預測後恢復原尺寸。預測完成前仍禁止拖動染色體。
3. **漂浮不整條越界**：對原版配對與分套散開動畫的目標位置加入圓形邊界限制；漂浮時放寬細胞壁的碰撞留白，允許少量染色體尖端貼出細胞外，不改漂浮速度、磁吸、使用者拖曳與計數反應。

### 前一版 6 項功能（完整保留）

1. **精子預測題**：改為「這隻果蠅有10條染色體，那精子內有多少條染色體？」；移除題目下方多餘說明。跳鼠同樣套用其染色體數量。
2. **配子表格顏色**：新版預測／核對表中，體染色體以藍色、性染色體以粉紅色區分。原版實際染色體的顏色、形狀完全沒改。
3. **簡短答對回饋**：例如「2套，完全正確！」；答錯時簡潔顯示正確值與原預測。精子、卵子的五項比對仍保留。
4. **另一性別挑戰**：系統記錄果蠅受精後寶寶性別；進入跳鼠的精子操作前，邀請試著產生另一種性別的寶寶，也能選擇自由操作。結果依學生真正選入精子的性染色體決定，系統不會替學生指定。**這是 XX/XY 教學模型，不是現實中能自主決定子女性別的操作方法。**
5. **牡蠣高中先修自選**：跳鼠完成後出現「牡蠣是高中課程，想挑戰看看嗎？」選「好」即開始牡蠣；選「還是回去多操作多複習幾次鞏固記憶」可複習已完成的果蠅或跳鼠，之後仍有「準備好了，挑戰牡蠣」入口。三關全通關後才開放三關自由重練。
6. **漂浮碰撞評估**：前版原封保留原版物理；本版依使用者新增要求，僅針對邊界越界修正，並保留漂浮速度、`+1`、磁吸和手指拖曳。

## 原版保護與檔案結構

- `index.html`：原版動畫與染色體互動為主體，只加入必要的流程接點。
- `learning-additions.js`：預測／核對、挑戰提醒、解鎖與進階選關。
- `learning-additions.css`：僅處理新增視窗和表格的顏色。
- `01-2.webp` 等 16 張 WebP：原圖片無損轉檔，保留透明度與圖像細節；`11.webp` 為先前確認的跳鼠交配插圖。
- 注意：原版 GSAP/Draggable 仍由 cdnjs 載入。**正式操作需要可以連接該 CDN。**

## 本版測試與限制

- 版面模擬（Chromium）：1366×768、1180×820、1024×768、768×1024、768×820、800×600、600×650，七種尺寸的預測卡片皆沒有和細胞區域重疊；完成預測後小螢幕細胞比例回復 1。沒有 JavaScript 例外。
- 漂浮邊界模擬：500 次物理更新未出現非有限數值，180 組極端動畫目標位置均被限制於設定的圓形邊界；最大染色體尖端越界約 13px，屬容許的部分突出。
- 已通過新增程式與原版內嵌 JavaScript 的語法檢查，以及前一版程式差異檢查：**沒有變動顏色、`+1`、點擊停止、磁吸和關卡核心**。
- 真正 GSAP、Draggable、iPad Safari 的完整手指操作仍需 GitHub 部署後實機驗收。瀏覽器模擬使用 GSAP 簡化替身，只驗證新增版面及基本邏輯，不代表真正動畫全部通關。
