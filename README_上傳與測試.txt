生命的藍圖 2.0｜完整 GitHub Pages 網站包
====================================
本 ZIP 已包含可以獨立執行的整個網站，不需要再使用升級工具，也不必先部署原版網站。

【GitHub 全選上傳】
1. 在電腦下載並「解壓縮」本 ZIP。請不要將 ZIP 檔直接上傳 GitHub；GitHub 不會自動替你解壓縮。
2. 前往 GitHub，按右上角「+」→「New repository」，建立全新儲存庫（例如 Chromosome-Review）。
3. 進入新儲存庫 → Add file → Upload files。
4. 打開解壓縮後的資料夾，按 Ctrl+A（或 Command+A）選取全部檔案，拖入上傳區；按 Commit changes。
5. Settings → Pages → Build and deployment → Source 選 Deploy from a branch；Branch 選 main；資料夾選 / (root)，Save。
6. 待 GitHub Pages 建置完成後，即可從 Settings → Pages 中找到新網址。

【內容】
- index.html：網站入口
- style.css：全版鎖定、橫向優先、直向可關閉提示、版面樣式
- app.js：遊戲流程、動畫、拖放、預測與驗證、解鎖與本機進度紀錄
- 01.webp 至 11.webp 等 16 張圖片：原圖壓縮及跳鼠交配圖
- 本說明檔

【主要功能】
- 首次依序練習：果蠅(10條) → 跳鼠(12條) → 牡蠣(3套12條)
- 計算「條」不先預測；「對/組」、「套」、配子、受精卵先預測後操作及核對
- 精子與卵子五項數量表格、答錯仍可繼續學習
- 配對拖曳、點選替代操作、拆開已配好的染色體
- 套數及配子拖放操作，能退回重放
- 跳鼠交配插畫、牡蠣體外受精笑話
- 全部通關後自由重練；完成紀錄存於同一瀏覽器 localStorage
- 無 CDN 套件，圖片在網站本機載入

【實機驗收建議】
- iPad Safari（橫向）：果蠅的計數、配對、拆開、分套、精子/卵子拖曳與答案核對。
- iPad Safari（橫向）：跳鼠12條染色體與交配圖，不能直接跳過這關。
- iPad Safari（橫向）：牡蠣三套與「牡蠣是體外受精，你在期待什麼...= =？」。
- 通關後：重新進站、直接回跳鼠/牡蠣重練。
- iPad（直向）：關閉旋轉提示後，仍可操作；頁面不可捲動。
- 檢查學校慢速網路下，圖片是否能快速載入。

【版本提醒】
這是根據確認規格重新整理的獨立 2.0 網站，不是舊站 index.html 的逐行原封不動複製。會保留染色體拖曳、配對與階段複習的教學精神，但版面、動畫與部分操作細節可能與舊版不同。
已完成 Chromium 自動流程測試；尚未經學校實際 iPad Safari 驗收，建議先用新儲存庫測試，不要覆蓋你最滿意的舊版網站。

【科學註記】
關卡的染色體條數刻意設計為教學簡化模型，不代表圖中物種的真實染色體數。三倍體生殖力降低，不應解釋成所有三倍體都絕對不可能產生配子或後代。
